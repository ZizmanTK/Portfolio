(02) Three projects
2023 — now

01 LLM agent · RAG BASSETTI · since 2024 internal name: TxBotin production

TEEXMA chatbot

Engineers ask a question in plain language. The chatbot answers from their company’s documents and from the data in TEEXMA.

My part
I built most of it: document search (RAG), queries on TEEXMA data, the agent (LangGraph), the API and the chat interface. I also build custom multi-step analysis workflows for individual customers.
Status
In production at several BASSETTI customers since early 2026. Announced with TEEXMA 7 in March 2026. BASSETTI’s TEEXMA 7 announcement ↗
Stack
LangGraph · LangChain · RAG · Python · Angular

How it works

One agent with tools. It reads the customer’s data model before it queries anything, calls TEEXMA tools, checks what comes back and retries when a call fails. Each customer chooses the model it runs on.

02 No-code ML BASSETTI · 2024–25 formerly REMINDpart of TEEXMA 7

Analysis & Prediction

Machine learning without code for materials engineers: prediction, clustering and anomaly detection on their own data, inside TEEXMA.

My part
Core developer in a small team. I built the ML workflows, the data import (Excel, CSV, TEEXMA) and the charts and statistics.
How it works
An engineer imports a dataset, explores it with histograms, correlation matrices and scatter plots, then runs prediction, clustering or anomaly detection without writing code.
Status
Part of TEEXMA 7, announced in March 2026. It began as REMIND, the R&I project I joined as an intern in 2024. BASSETTI’s TEEXMA 7 announcement ↗ The demo (BASSETTI, in French) ↗ Techniques de l’Ingénieur article (in French) ↗
Stack
Angular · Django · scikit-learn · MongoDB · Docker

03 Computer vision ArcelorMittal · 2023 prototype at ArcelorMittal

CoilCheck

Finds surface defects on steel coils before packaging and shows operators where to look, with a heatmap.

My part
My six-month internship project at ArcelorMittal. I built the prototype: image processing with OpenCV, then supervised CNNs and anomaly-detection models, trained and compared on real coil images.
How it works
Each coil image gets a heatmap of suspect areas and a verdict with a score.
Status
Working prototype at the end of the internship.
Stack
Python · TensorFlow · Anomalib · OpenCV · CNNs
